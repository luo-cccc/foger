# InkOS 文档

本目录只维护当前 Episode v2 系统的长期文档。一次性审查记录、真实模型运行流水账、临时测试报告和已经完成的阶段计划不作为项目规范保存；其中仍有长期价值的结论应整理进更新记录。

## 文档入口

- [架构说明](architecture.md)：权威数据、包边界、单集流水线、状态机、事务、Canon 与恢复规则。
- [运行与维护](operations.md)：生产命令、异常恢复、验证、清理、生产数据隔离和发布检查。
- [更新记录](releases/release-notes.md)：按日期保留用户可见变化和重要历史决策。
- [贡献指南](../CONTRIBUTING.md)：开发约束、测试层级、文档职责和污染防护。
- [脚本索引](../scripts/README.md)：质量门禁、压力测试、清理和发布脚本。

产品安装与基本使用见项目根目录 [README](../README.md)。

## 文档维护规则

- README 只保留当前产品说明和最新日期块。
- 架构与运维文档描述当前行为，不记录某次修复过程、旧测试数量或具体付费项目剧情。
- 完整历史放在 `releases/release-notes.md`；原始测试输出留在 Git 忽略的临时目录，并由 `pnpm clean` 清理。
- 删除或移动文档时，使用 `rg` 检查仓库引用并运行 `pnpm verify`。
